# Website Portofolio — Gilang Muhamad Husen

Website satu halaman bertema premium pharmaceutical untuk artikel:
"Belajar, Bekerja, dan Berkembang di PT Meprofarm Pharmaceutical Industries".

## Struktur
- `index.html` — halaman utama
- `style.css` — desain responsif
- `script.js` — animasi, menu mobile, dan kontrol musik
- `assets/profile.jpg` — isi dengan foto profil Anda
- `assets/music.mp3` — isi dengan instrumen/musik yang Anda miliki atau berlisensi

## Cara menjalankan di VS Code
1. Extract folder project.
2. Buka folder di Visual Studio Code.
3. Masukkan foto Anda ke `assets/profile.jpg`.
4. Masukkan file musik MP3 ke `assets/music.mp3`.
5. Buka `index.html` dengan Live Server.

## Catatan autoplay
Browser modern sering memblokir autoplay audio yang bersuara. Website sudah mencoba autoplay ketika halaman dibuka dan otomatis mencoba memulai musik pada interaksi pertama pengguna. Tombol "Musik" juga bisa digunakan untuk menyalakan/mematikan musik.

## Foto
Jika `assets/profile.jpg` belum tersedia, halaman otomatis menampilkan placeholder "GMH".
